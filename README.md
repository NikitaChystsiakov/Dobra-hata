# Добра Хата — калькулятор стоимости

Next.js 16 (App Router), без Tailwind и UI-библиотек. Одна страница `/`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
node --test lib/pricing.test.ts   # контрольные примеры из ТЗ
```

## Где что менять

| Что | Где |
|---|---|
| Тарифы, минимумы, ставка бани, залог, срок действия прайса | `lib/pricing.config.ts` |
| Праздники (фиксированные и Радуница по годам) | `lib/pricing.config.ts` → `HOLIDAYS_FIXED`, `HOLIDAYS_BY_YEAR` |
| Демо-занятые даты в календаре | `lib/pricing.config.ts` → `DEMO_BUSY_OFFSETS` (смещения от сегодня) |
| Телефоны, Instagram, адрес | `lib/pricing.config.ts` → `CONTACTS` |
| Фото и подписи | `lib/photos.ts` |
| Цвета обеих тем, вся вёрстка | `app/globals.css` (токены в `:root` — тёмная, `[data-theme="light"]` — светлая) |
| Шрифты (три пары на выбор) | `app/layout.tsx` + `[data-font]` в `globals.css` |
| Логика расчёта | `lib/pricing.ts` — `quote()` |

## Состояние в ссылке

`/?f=a&d=2026-10-03&g=40&b=1` — формат (a/b/c), дата, гостей, баня. Ссылку можно отправить — откроется с той же суммой. Сервер читает параметры при рендере (`app/page.tsx`), браузер обновляет их при каждом изменении.

## Фото

`public/photos/*.jpg` — обработанные снимки клиента (срезан водяной знак, ширина 1200, насыщенность −20 %). В каждом JPEG в комментарии записан источник. Оригиналы — в `../материалы/фото/`.

## Тема и шрифты

Тёмная по умолчанию, светлая по переключателю. Выбор хранится в `localStorage.theme`; параметр `?theme=light|dark` в ссылке имеет приоритет (для демонстрации клиенту).

`?font=a|b|c` — переключение пар шрифтов для сравнения: a — Onest + Lora (заголовки), b — Manrope везде, c — Montserrat + Merriweather. После выбора оставить одну пару и убрать остальные из `app/layout.tsx`.
